## Why

tenuki を対局のたびに EC2 で起動して指させるが、今は対局の様子をブラウザで見る手段がない（tui の Rails 版はローカル前提）。サーバのコードも同期の仕組みも足さずに、EC2 上の受信ログ `log/*.log` を誰でもブラウザからリアルタイムに見られるようにしたい。

## What Changes

- `viewer/index.html` を新規追加する。HTML・CSS・JS を 1 ファイルにまとめ、フレームワークもビルドも使わない
- `viewer/log` を `../log` へのシンボリックリンクとして追加する
- 配信は `python3 -m http.server 8000 -d viewer` で行う（運用手順として README に記載）。配信対象は `viewer/` に限定し、`tenuki.conf` やソース・評価関数ファイルは外から見えないようにする
- ビューアは次のことをする
  - `log/` のディレクトリ一覧から対局の一覧を作り、対局中かどうかを示す
  - 「最新を追う」か特定のログかを選べ、選択を URL のハッシュに残す
  - 平手から指し手を再生して盤面・持ち駒・最終手・対局者名・結果を表示する
  - 指し手リストで過去の手に戻れる。最新手を見ているときだけ新しい手に追従する
  - 2 秒ごとに取り直す。終局したログは取り直さない
- tenuki 本体（`source/`）と `misc/loop.sh` は変更しない

## Capabilities

### New Capabilities
- `game-viewer`: 受信ログ（`log/*.log`）を読んで対局を表示するブラウザ用ビューアの振る舞い（一覧・選択・再生・追従・表示）と、その配信のしかた

### Modified Capabilities

## Impact

- 新規ファイル: `viewer/index.html`、`viewer/log`（シンボリックリンク）
- `README.md` に配信手順を追記
- 運用: EC2 の SG で 8000 番を `0.0.0.0/0` に開ける。HTTP 平文・認証なしで公開し、URL はインスタンス起動ごとに変わり、インスタンス停止後は過去の棋譜は見られない（いずれも受け入れ済み）
- 対象外: 読み筋・評価値の表示、認証と HTTPS、S3 や SSH トンネル、停止後の閲覧、tui（Rails）の改修
