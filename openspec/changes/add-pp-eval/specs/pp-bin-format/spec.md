## Purpose

PP 評価関数が使う評価関数ファイル pp.bin のバイナリ形式、駒のインデックス体系、ファイルが満たす対称性を定める。

## ADDED Requirements

### Requirement: ファイル形式
pp.bin は 10,988,672 バイトのファイルでなければならない (SHALL)。
pp.bin には 2344 × 2344 = 5,494,336 個の int16_t がリトルエンディアンで格納される。
2344 は1つの駒が取りうる場合の数である。
値は行優先で格納され、pp[a][b] はファイル先頭から (a × 2344 + b) × 2 バイト目に置かれる。
pp[a][b] には、インデックス a の駒とインデックス b の駒の組み合わせの評価値が格納される。

#### Scenario: サイズの検査
- **WHEN** 10,988,672 バイトでないファイルを pp.bin として読み込む
- **THEN** 読み込みはエラーになる

#### Scenario: エントリの位置
- **WHEN** pp[2263][2262] を読む
- **THEN** ファイル先頭から 10,613,468 バイト目の2バイトを int16_t（リトルエンディアン）として読む

### Requirement: 盤面のアドレス
盤上の升のアドレスは図1に従わなければならない (SHALL)。
f 筋 r 段の升のアドレスは (f - 1) × 9 + (r - 1) である。
このアドレスは Position.board の添字と一致する。

### Requirement: 駒のインデックス
駒のインデックスは表1に従わなければならない (SHALL)。
`b_` は先手、`w_` は後手、`h_` は持ち駒を表す。
盤上の駒のインデックスは、その駒の Index に升のアドレスを足したものである。
持ち駒のインデックスは、その駒の Index に (k - 1) を足したものである。k はその種類の持ち駒の何枚目かを表す（1 から数える）。
成駒は金と区別し、独立したインデックスを持つ。玉も他の駒と同様にインデックスを持つ。

#### Scenario: 持ち駒のインデックス
- **WHEN** 先手の持ち駒の歩の1枚目、2枚目、後手の持ち駒の歩の1枚目、2枚目のインデックスを求める
- **THEN** それぞれ 0, 1, 18, 19 になる

#### Scenario: 盤上の駒のインデックス
- **WHEN** 先手玉が 11, 12, 88, 99 にいる場合と、後手玉が 11 にいる場合のインデックスを求める
- **THEN** それぞれ 2182, 2183, 2252, 2262, 2263 になる

#### Scenario: 2駒の評価値
- **WHEN** 後手玉が 11、先手玉が 99 にいる組み合わせの評価値を引く
- **THEN** pp[2263][2262] の値を使う

### Requirement: 先手視点
pp.bin の評価値は先手視点で格納されなければならない (SHALL)。
すなわち、正の値は先手有利、負の値は後手有利を表す。手番には依存しない。

#### Scenario: 評価値の符号
- **WHEN** 先手に有利な2駒の組み合わせの評価値を読む
- **THEN** 手番がどちらであっても、その値は正である

### Requirement: 行列の対称
pp.bin は、すべての a, b について pp[a][b] == pp[b][a] を満たさなければならない (SHALL)。

#### Scenario: 順序の入れ替え
- **WHEN** 任意のインデックス a, b について pp[a][b] と pp[b][a] を読む
- **THEN** 2つの値は等しい

### Requirement: 先後対称
pp.bin は、すべての a, b について pp[a][b] == -pp[inv(a)][inv(b)] を満たさなければならない (SHALL)。
inv は盤を180度回して先後を入れ替える写像である：
- 盤上の駒：同じ種類で手番が逆の駒になり、升のアドレス i は 80 - i になる
- 持ち駒：同じ種類で手番が逆の持ち駒の、同じ k 枚目になる

#### Scenario: 先後を入れ替えた組み合わせ
- **WHEN** 先手玉 99 (2262) と後手玉 11 (2263) の組み合わせを読む
- **THEN** inv(2262) = 2263、inv(2263) = 2262 なので、pp[2262][2263] == -pp[2263][2262] になる。行列の対称と合わせると、この値は 0 になる

#### Scenario: 持ち駒の先後対称
- **WHEN** 先手の持ち駒の歩1枚目 (0) と先手玉 88 (2252) の組み合わせを読む
- **THEN** pp[0][2252] == -pp[18][2273] になる（後手の持ち駒の歩1枚目、後手玉 22）
