# Spec Delta

## Purpose

tenuki が書く受信ログ（`log/*.log`）を読み、進行中・終局後の対局をブラウザで誰でもリアルタイムに見られるようにするビューア。

## ADDED Requirements

### Requirement: 配信対象の限定
ビューアは `viewer/` ディレクトリだけを静的に配信して使えなければならない（SHALL）。`viewer/log` は `../log` へのシンボリックリンクとしてリポジトリに含め、受信ログはこのリンク経由でのみ公開する。リポジトリ直下のファイル（設定ファイル・評価関数ファイル・ソース）は配信対象に含めない。

#### Scenario: ビューアとログが見える
- **WHEN** リポジトリ直下で `python3 -m http.server 8000 -d viewer` を起動し、ブラウザで `http://<host>:8000/` を開く
- **THEN** ビューアが表示され、`log/` 以下の `*.log` を読み込める

#### Scenario: 設定ファイルは見えない
- **WHEN** 同じサーバに `/tenuki.conf` や `/../tenuki.conf` を要求する
- **THEN** その内容は返らない

### Requirement: 対局一覧
ビューアは `log/` のディレクトリ一覧から名前が `.log` で終わるファイルだけを拾い、ファイル名の新しい順（降順）に一覧表示しなければならない（SHALL）。終局行を含まないログには「対局中」の印を付ける。

#### Scenario: 新しい順に並ぶ
- **WHEN** `log/` に `20261113T194530.log` と `20261113T210512.log` と `.keep` がある
- **THEN** 一覧は `20261113T210512.log`、`20261113T194530.log` の順に 2 件だけ表示される

#### Scenario: 対局中の印
- **WHEN** あるログに `#WIN`・`#LOSE`・`#DRAW`・`#CENSORED`・`#CHUDAN` のいずれの行もない
- **THEN** そのログには対局中の印が付く

#### Scenario: ログが 1 つもない
- **WHEN** `log/` に `*.log` が 1 つもない
- **THEN** 一覧は空で、盤面は表示せずエラーにもならない

### Requirement: 表示するログの選択
ビューアは「最新を追う」と個別のログのどちらかを選べなければならない（SHALL）。既定は「最新を追う」。選択は URL のハッシュ（例: `#20261113T202200.log`、最新を追うときはハッシュなし）に反映し、ハッシュから選択を復元する。

#### Scenario: 最新を追う
- **WHEN** 「最新を追う」を選んでいる間に、新しいログが `log/` に作られる
- **THEN** 次の更新で表示が新しいログに切り替わる

#### Scenario: 個別のログに固定
- **WHEN** 個別のログを選んでいる間に、新しいログが作られる
- **THEN** 表示は選んだログのまま切り替わらず、一覧には新しいログが加わる

#### Scenario: ハッシュから復元
- **WHEN** `index.html#20261113T202200.log` を開く
- **THEN** そのログが選ばれた状態で表示される

#### Scenario: 存在しないログのハッシュ
- **WHEN** ハッシュが一覧にないファイル名を指している
- **THEN** 「最新を追う」として表示する

### Requirement: 指し手の再生
ビューアは平手の初期局面から、ログ中の `^[+-]\d{4}[A-Z]{2}` に一致する行を出現順に指し手として適用して局面を求めなければならない（SHALL）。Game_Summary 内の初期指し手（ブイ）も同じ規則で通常の指し手として扱う。

#### Scenario: ブイを含む
- **WHEN** ログの `BEGIN Position` 内に `+2726FU,T12` があり、その後に `-3334FU,T3` がある
- **THEN** 指し手リストは `+2726FU`、`-3334FU` の 2 手になり、2 手目の局面が表示される

#### Scenario: 指し手でない行は無視する
- **WHEN** ログに `%TORYO,T5`、`To_Move:+`、`P1-KY-KE...` などの行がある
- **THEN** それらは指し手として扱われない

#### Scenario: 0 手のログ
- **WHEN** ログに指し手が 1 つもない（ログインに失敗した、対局開始前など）
- **THEN** 平手の初期局面を表示し、エラーにならない

#### Scenario: 駒を取る・成る
- **WHEN** 移動先に相手の駒がある指し手や、駒種が成駒に変わる指し手を適用する
- **THEN** 取った駒は成りを戻した駒種で手番側の持ち駒に加わり、移動した駒は指し手の駒種で置かれる

### Requirement: 盤面の表示
ビューアは白地の 9×9 の盤に駒を黒い漢字 1 文字で表示しなければならない（SHALL）。後手の駒は 180 度回転させる。字は歩・香・桂・銀・金・角・飛・玉、成駒は と・杏・圭・全・馬・竜 とし、玉は先後とも「玉」。盤の上に筋（9〜1）、右に段（一〜九）を表示する。

#### Scenario: 初期局面
- **WHEN** 0 手目を表示する
- **THEN** 一段目に後手の 香桂銀金玉金銀桂香 が逆さに、九段目に先手の同じ駒が正立で並ぶ

#### Scenario: 成駒
- **WHEN** 先手の歩が成った局面（`TO`）を表示する
- **THEN** そのマスに正立の「と」が表示される

### Requirement: 最終手の強調
ビューアは表示中の局面の直前の指し手の移動先マスを、薄い背景色で示さなければならない（SHALL）。0 手目では強調しない。

#### Scenario: 移動先が強調される
- **WHEN** `+7776FU` を指した直後の局面を表示する
- **THEN** 7六のマスだけが薄い背景色になる

### Requirement: 持ち駒の表示
ビューアは持ち駒を「歩3 角」のように駒の字と枚数（1 枚のときは字のみ）で表示しなければならない（SHALL）。後手の持ち駒は盤の上、先手の持ち駒は盤の下に置く。並び順は 飛・角・金・銀・桂・香・歩。

#### Scenario: 複数枚
- **WHEN** 先手が歩を 3 枚、角を 1 枚持っている
- **THEN** 盤の下に「角 歩3」と表示される

#### Scenario: 持ち駒なし
- **WHEN** 後手が持ち駒を持っていない
- **THEN** 盤の上の持ち駒欄は空（または「なし」）で、エラーにならない

### Requirement: 対局者と結果の表示
ビューアは Game_Summary の `Name+:`・`Name-:` から対局者名を ▲（先手）・△（後手）付きで表示しなければならない（SHALL）。終局したログでは、`Your_Turn:` と `#WIN`/`#LOSE`/`#DRAW` から勝者（または引き分け）を、`#CENSORED`/`#CHUDAN` なら中断を表示し、その直前の終局理由行（`#RESIGN`・`#TIME_UP` など）があれば併せて表示する。

#### Scenario: tenuki が後手で勝つ
- **WHEN** ログに `Name+:alice`、`Name-:tenuki`、`Your_Turn:-`、`#RESIGN`、`#WIN` がある
- **THEN** 「▲alice △tenuki」と、後手（△tenuki）の勝ちであることと、理由 `#RESIGN` が表示される

#### Scenario: 対局者名がまだない
- **WHEN** ログに Game_Summary がまだ届いていない
- **THEN** 対局者名欄は空で、エラーにならない

### Requirement: 指し手リストと局面の閲覧
ビューアは「開始局面」と各指し手を手数付きで並べた指し手リストを表示し、項目を選ぶとその手数の局面を表示しなければならない（SHALL）。キーボードの上下キーで前後の手に移れる。

#### Scenario: 過去の手を選ぶ
- **WHEN** 50 手まで進んだログで 20 手目を選ぶ
- **THEN** 20 手目を指した直後の局面と、その手の最終手強調が表示される

### Requirement: 最新手への追従
ビューアは、最新手（指し手リストの最後）を表示しているときに限り、更新で手が増えたら最新手へ表示を進めなければならない（SHALL）。過去の手を表示しているときは、手が増えても表示中の手数を変えない。ログが切り替わったときは、新しいログの最新手を表示する。

#### Scenario: 最新手を見ている
- **WHEN** 最新の 30 手目を表示中に、ログが 31 手目まで伸びる
- **THEN** 表示は 31 手目に進む

#### Scenario: 過去の手を見ている
- **WHEN** 20 手目を表示中に、ログが 31 手目まで伸びる
- **THEN** 表示は 20 手目のままで、指し手リストには 31 手目まで並ぶ

### Requirement: 定期更新
ビューアは 2 秒ごとに対局一覧と表示中のログを取り直さなければならない（SHALL）。取得時はブラウザのキャッシュを使わない。表示中のログが終局していれば、そのログはそれ以上取り直さない（一覧の取り直しは続ける）。取得に失敗しても直前の表示を保ち、次の周期で再試行する。

#### Scenario: 手が進む
- **WHEN** 対局中のログに新しい指し手行が追記される
- **THEN** 遅くとも約 2 秒後に指し手リストに反映される

#### Scenario: 終局後
- **WHEN** 表示中のログに `#WIN` 行が現れた後
- **THEN** そのログへのリクエストは発生しなくなる

#### Scenario: 一時的な取得失敗
- **WHEN** サーバが一時的に応答しない
- **THEN** 直前の盤面を表示したまま、次の周期で再取得する
